# Test and development dependencies.
#
#     pip install -r requirements-dev.txt
#
# ---------------------------------------------------------------------------
# This file composes the three deploy manifests
# ---------------------------------------------------------------------------
# Each deploy manifest stays authoritative for its own runtime and is
# referenced rather than restated, so a pin can never drift between what is
# deployed and what is tested. Only the test-only libraries are added on top.
#
# Composition is possible because all three manifests agree on boto3:
# backend/ and etl/ pin it exactly, and the agent's packages set only floors
# at or below that pin:
#
#   backend/requirements.txt  boto3==1.43.92
#   etl/requirements.txt      boto3==1.43.92
#   agent/...                 bedrock-agentcore==1.19.0            -> boto3>=1.43.31
#                             bedrock-agentcore-starter-toolkit    -> boto3>=1.42.1
#                             strands-agents==1.50.2               -> boto3>=1.26.0,<2
#
# Lowering the backend/etl pin below 1.43.31 reintroduces a conflict that pip
# reports as ResolutionImpossible, which is what this file previously had to
# work around by restating the dependencies instead of composing them.
# ---------------------------------------------------------------------------

# Backend and ETL runtime deps.
-r backend/requirements.txt
-r etl/requirements.txt

# Agent runtime deps. Required, not optional: tests/test_agent_main.py,
# test_github_tool.py, test_gitlab_tool.py, test_kiro_data_tool.py,
# test_gitlab_provider_properties.py and test_ssm_token.py import agent code,
# which imports bedrock_agentcore, pydantic and strands at module top level
# with no test stubbing them. Omitting this fails pytest *collection* with six
# errors, before a single assertion runs.
-r agent/app/GitCorrelationAgent/requirements.txt

# Test-only libraries. Exact pins so an upstream default-behaviour change
# cannot surface as an unexplained failure on an unrelated pull request.
pytest==9.1.1
moto==5.2.3
hypothesis==6.167.1
